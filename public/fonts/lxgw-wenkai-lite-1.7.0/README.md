# Letter scene typeface

LXGW WenKai Lite Regular, self-hosted from `lxgw-wenkai-lite-webfont@1.7.0`.

- Typeface upstream: https://github.com/lxgw/LxgwWenKai-Lite (LXGW, based on Fontworks Klee)
- Webfont packaging: https://github.com/chawyehsu/lxgw-wenkai-webfont
- Exact distribution: https://www.npmjs.com/package/lxgw-wenkai-lite-webfont/v/1.7.0
- `regular.css` and its 97 WOFF2 subsets are copied unmodified from the distribution. Only regular weight is included (4,046,944 font bytes total); unicode ranges load only the glyph subsets used on a page.
- Font license: `OFL.txt` (SIL OFL 1.1); packaging license: `LICENSE` (MIT).
- Only the entertainment confession scene uses this family. `font-display: swap` preserves immediate readable text, and fonts do not gate the curtain or work readiness. No runtime CDN requests.
