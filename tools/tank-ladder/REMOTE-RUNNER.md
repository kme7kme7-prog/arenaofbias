# Windows 计算节点

网站保存账号、封存任务、私有源码和结果；计算节点主动领取单场任务，在新建子进程中的 QuickJS/WASM 运行，上传回放。浏览器不能提交赛果。计算节点是运营方可信设备，不是玩家众包计算。

## 本机验证与两台机器的区别

同机可以运行两个终端验证流程；真正隔离主站文件，需要在另一台电脑或虚拟机运行节点，并使用专用低权限账户。独立进程只隔离地址空间，不自动隔离文件系统或网络。Node 堆上限不等于整机/WASM 总内存上限；当前还没有自动安装 Windows Job Object、服务账户、防火墙或 VM。

默认节点一次只算一场；可以把 TANK_RUNNER_SLOTS 设为 1–8，协调端也有独立并发上限。先测温度和耗时再增并发。这里算的是 JavaScript Bot 和物理规则，不是大模型推理；无 GPU 执行路径。不要因为机器变慢就悄悄提高赛季预算。

本轮提供两个启动配置：i3-9100T / 16GB 默认 1 场并发，i5-9400 / 16GB 默认 2 场并发。它们运行代码和赛季指纹完全一致，只改变同时运行的场数，尚未在这两台实机测量。若两台同时接入并希望合计跑 3 场，把协调端 TANK_RUNNER_SLOTS 设为 3。正式赛季需验证两机超时率、耗时分布；若有显著差异，应先只指定一种已校准硬件，不能直接混算后宣称完全公平。

## 协调端（网站所在机器）

需要 Node.js >=22.13 和本目录 npm ci 安装的依赖。首次在可信终端生成密钥文件，勿覆盖已有密钥、不要提交 Git 或放进网页目录：

```powershell
node -e "require('fs').writeFileSync('runner-token.txt',require('crypto').randomBytes(32).toString('hex'),{flag:'wx'})"
$env:TANK_RUNNER_TOKEN_FILE = (Resolve-Path ./runner-token.txt).Path
$env:TANK_RUNNER_SLOTS = '2'
$env:TANK_LADDER_DATA = 'C:\TankData\remote-trial-01'
node server.mjs
```

网页监听 127.0.0.1:5472，计算接口监听 127.0.0.1:5473。设置节点密钥后协调端停止本地计算，只发任务。没有设置密钥时仍可本地单进程调度、逐场独立子进程执行。

运行指纹已改变，必须使用新试赛目录；不要删除或重写旧数据库的 profile 来强行复用旧成绩。正式站账号集成尚未完成，此处不要直接反向代理为匿名公网投稿服务。

## 打包给笔记本

在协调端项目的 tools/tank-ladder 中运行：

```powershell
node package-runner.mjs
```

复制输出的整个目录到笔记本。包内只有运行代码、引擎和依赖锁文件，不包含投稿、数据库、密钥或 node_modules。保持目录结构，不要只拿 runner.mjs。笔记本安装相同版本的 Node.js，联网首次运行会安装锁定依赖。

通过可信渠道另行复制 runner-token.txt 至包根目录，限制文件只允许节点账户读取。计算子进程不会继承此密钥环境变量，但没有 OS 账户隔离时仍不能承诺逃逸后读不到磁盘。

## 连接服务器

在笔记本终端保持 SSH 隧道运行（替换账户和服务器地址）：

```powershell
ssh -N -L 127.0.0.1:5473:127.0.0.1:5473 -o ExitOnForwardFailure=yes -o ServerAliveInterval=15 -o ServerAliveCountMax=3 runner-tunnel@YOUR_SERVER
```

使用单独的转发账户/密钥，只允许转发到服务器 127.0.0.1:5473，不给主站管理权限；首次核对服务器主机指纹，不关闭主机密钥校验。笔记本只主动连接 SSH，无需路由器端口映射。服务器的 SSH 和专用账户需由管理员实际配置，脚本不会创建它们。

然后双击 start-runner.cmd。同机测试可省掉 SSH。Ctrl+C 停节点，不要关协调端；未完成任务最多 180 秒后回队列，重新使用原封存地图、种子、选手和座位。允许睡眠会暂停计算，长时间无人值守时应接电并调整睡眠策略。

## 协议与安全边界

- 256-bit 节点密钥、每任务随机租约，固定 180 秒有效；验证任务 15 秒、比赛 120 秒子进程硬截止。
- 密钥仅访问计算端点；普通网页 Cookie 无效，带 Origin 的浏览器请求被拒绝。源码只发送给已认证运营节点。
- 引擎/运行器指纹不匹配拒领；过期/已消耗租约拒收；重启重排未完成任务，旧租约失效。结果和评级事务提交，重复投递不重复计分。
- 结果正文最大 32 MiB，并检查排名基本类型、四席和封存清单。**这不是对恶意计算节点的数学验证**：持有节点密钥的人可以伪造结果，因此只给自己控制的设备，禁止发给参赛者。
- 单场异常不把原始 Bot 堆栈/源码写入公开错误。旧成绩不被失败场覆盖。网络回传失败有限重试，仍失败则等租约回收；不保证正好一次计算，但保证同任务最多一次计分。
- 未完成：主站真实身份接入、OS 级账户/资源/网络隔离部署、全局磁盘配额与保留策略、告警/封禁和目标硬件预算校准。当前是可测试的拆分原型，不是公网安全审计结论。
