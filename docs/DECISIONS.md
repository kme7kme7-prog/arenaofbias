## 014 · 换组时上一轮作品整体回避

- 日期：2026-09-08 ｜ 状态：生效
- 决定："换一组"时，上一轮出场的两份结果下一轮均不参与配对（`pickMatchup` 按 id 不相交过滤）；无可避开组合时回退全量
- 理由/被否方案：已揭晓身份的作品再次出场会被凭记忆认出，盲测失效；原规则只避开相同组合，单个作品换对手重现仍有泄漏
- 来源：本轮对话用户拍板（原话："当轮出现的两个选项，下一轮不可以再次出现，否则就是泄漏模型信息了"）

## 015 · 作品 iframe 沙箱放行同源

- 日期：2026-09-08 ｜ 状态：生效
- 决定：`app/page.tsx` 作品 iframe 的 sandbox 由 `allow-scripts` 改为 `allow-scripts allow-same-origin`
- 理由/被否方案：仅 `allow-scripts` 下 iframe 为不透明源，Three.js 等初始化中访问同源受限 API 会直接崩掉，3D 作品黑屏/卡在加载态；作品为本地一方内容而非用户上传，同源放行风险可接受。未来若开放外部投稿须重新评估
- 来源：本轮接入真实模型输出时发现并经用户确认

## 016 · 组件按需引入，shadcn CLI 不入依赖

- 日期：2026-09-09 ｜ 状态：生效
- 决定：`components/ui/` 只保留实际使用的 button / dialog / tabs / textarea 四个组件；从依赖中移除 shadcn CLI、@shadcn/react 及仅服务未使用组件的包（cmdk、embla-carousel-react、input-otp、react-day-picker、react-resizable-panels、recharts、date-fns）；新增组件用 `npx shadcn@latest add` 按需添加；原 `shadcn/tailwind.css` 用到的 data-* 状态变体内联在 `app/globals.css` 顶部
- 理由/被否方案：全量安装 58 个组件但只用 4 个，node_modules 白白多出约 135MB；被否方案：保留全量组件"以备不时之需"（用到再装，npm 缓存秒级恢复）
- 来源：本轮对话用户要求瘦身当前项目
