## 001–009（历史收编，2026-09-08）· 早期视觉与规则基线

- 001 · 视觉与动效走游戏式体验，不接受泛滥的极简 AI 产品样式。
- 002 · 首页保持轻盈版：纸灰绿 + 深墨 + 酸性黄，主入口深色底亮字；厚重立体效果被否（唯一例外见 013）。
- 003 · 入场退焦与遮挡：当前作品放大居中、非当前退焦；两张投票按钮一致退焦（opacity/blur/饱和度统一）并保持可见，由放大作品自然遮挡重叠区；不给 contender 加不对称 filter。
- 004 · VS 装饰限制在中央间隙；锁定提示内部呈现支持率，不用悬空进度条。
- 005 · 结果页不使用摘要小卡片、不做频道面板化。
- 006 · 评论按提示词聚合（"本提示词讨论"）；旧 API 的 side 字段仅为兼容保留，不能用于推断立场；将来做按模型的评论/投票必须存 modelId，不能只存左右位置（左右会随机交换，无阵营语义）。
- 007 · 评论需登录后才可发表；历史无主评论显示"匿名观测员 #XXXX"（防低门槛匿名刷评）。
- 008 · A/B 只是展示位置：抽组随机选组并随机分配左右；换组优先避开刚看过的组合（降低品牌印象与位置偏好影响）。
- 009 · `isDemo` 样例不计入模型数、不参与配对与随机竞技场，仅可在预览页查看。
