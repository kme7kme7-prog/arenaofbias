# 娱乐竞技场加载与过场稳定性排查

2026-10-04，本地完成。用户要求先排查现有卡顿，为后续新题型开发打基础。本轮没有实现对话题型，没有提交、推送或部署。

## 已修复的原因

| 原因 | 改动 | 验证 |
| --- | --- | --- |
| 目录 GET 及响应正文没有等待上限，网络挂起时路由可能一直 loading | 作品、题目、评分读取增加 12 秒取消期限，保留原成功、空清单和失败语义；写接口不改 | 挂起请求头/正文、调用者取消、空清单；浏览器挂起首轮目录后退出 loading |
| 退场要求连续三帧低于 250ms，持续低帧率下永远等不到 | 最多等 1.8 秒恢复帧率，然后以原有每帧推进上限继续退场；作品未就绪门禁保持 | 实际动画模块模拟持续 2fps，门禁关闭时仍遮挡，开门后有限时间移除；既有长掉帧冻结断言保持 |
| 页面在后台时作品渲染可暂停，但失败计时仍累计 | 作品就绪预算只累计页面可见时间，恢复前台后续用剩余预算 | 隐藏/恢复/反复切换/后台创建/监听清理，以及浏览器暂停 11.5 秒不换组 |
| 已恢复的上一轮占用了下一轮的唯一重试机会 | 换组进入 transition 就给下一轮独立预算，不等 ARRIVE 才重置 | 第一轮失败后恢复，第二轮再失败也刷新一次并成功；两次失败仍走既有空态 |
| 同题换组 setPair 后 effect 再运行，重复等待遮挡延迟并轮询旧 src | 遮挡后提交新 pair，下一次 effect 在 React 提交后的新 iframe 上等就绪，不重复播放等待 | 纸/墨色就绪与迟到通知回归、连续 15 次换组 |
| 图片入场会预加载并等待同题所有图片，未参赛慢图拖住当前对局 | 只等待本轮两件作品的资源；卸载清理预加载计时器与事件；换组检查当前图片节点完成 | 仅选中两张请求，未选中的 11 秒慢图不阻塞入场 |

## 本轮文件

- `lib/api.ts`、`lib/works.ts`、`lib/prompts.ts`、`lib/ratings.ts`：目录读取取消期限。
- `lib/loading-clock.ts`、`app/page.tsx`：前台加载时钟、重试预算、换组提交顺序、当前图片等待及清理。
- `lib/game-transitions.ts`、`scripts/check-game-transitions.mjs`：低帧率退场与不变量测试。
- `scripts/check-loading.mjs`、`scripts/validate-stability.mjs`：取消/时钟检查与五组隔离浏览器回归。
- 根 `HANDOFF.md` 与本报告：交接证据。同期首页缓存、投票分布等其他任务改动保留，不归入本报告产物。

本轮没有改共享后端、作品文件、数据库、77 个娱乐镜头参数、Gallery 或正式盲测探针。读取超时沿用现有失败处理，不把服务端明确返回的空目录回退成旧作品。

## Tabbit 真实作品与剩余限制

使用本地完整下载副本 `http://127.0.0.1:5441/`，只读真实目录，非 GET API 拦截为测试响应，没有实投票。中途本地服务不在监听，已用既有启动脚本恢复 5441/5190/5191；这不是线上故障证据。

- 008 文字题：一次同题继续约 2.842 秒，最终 voting、按钮可用、无残留过场、pageerror 0。保留原动画节拍，不能将整个耗时描述为网络等待。
- 011 飞机：初始两侧 canvas 都有，精简标记有效；一次继续约 21.085 秒，最终 voting、两侧 iframe、无残留过场、按钮可用、pageerror 0。
- 进一步分解另一组飞机：两侧 `aob:work-loading` 到 `aob:work-ready` 分别约 10.247 / 19.412 秒；最后就绪到 voting 约 0.577 秒。当前这一组长等待发生在作品就绪之前，不能归因于退场还卡了十几秒。
- 作品外部 Three.js/OrbitControls/环境模块下载约 1.7–2.5 秒；其中一件 DOMContentLoaded 约 10.3 秒，而 HTML 响应约 52ms。另观察到父页一次约 1 秒长任务。来源有外部依赖、作品初始化及共享渲染负载；这里只能确认样本，不能据此断言所有慢作品有同一个原因。
- 有些重型作品仍慢，本轮没有修改作者的模型生成、渲染循环或第三方依赖。后续优化需要按作品定位初始化/每帧成本，并保持娱乐独立适配；不能用超时强制报就绪来隐藏未完成的场景。

本轮不是全量作品内部功能审计，也不是所有硬件/网络的性能保证；真实生产缓存、并发及移动 GPU 尚未重测。可继续开发新题型，但需要独立定义其就绪/失败/卸载规则并接入这些回归。
