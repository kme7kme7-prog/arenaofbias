# 产品当前行为

本文描述当前已实现的产品行为：用户能感知到的规则与语义。长期愿景见 `README.md`；实现细节（字段、函数、文件结构）见 `docs/ARCHITECTURE.md`。

| --------- | ----------- | ------------------------------- | -------------------- |
| 001 鹈鹕大挑战 | 真实模型输出（整活集） | 20 份真实模型生成的单文件 SVG 动画（模型阵容偏整活：gpt-6-astra 各档、seed-2.1-pro、deepseek-v4 系列、GLM-5.3 等，同一模型多作品并存）；另有 1 份 isDemo 演示样例 | 参与配对（约 18 个模型、多组对局） |
| 002 最后一句  | 占位内容        | 两篇文字存于作品清单（现为内置 JSON，服务端 works 表同构），挂虚构模型名（墨池 / 回声） | 参与配对                 |

## 用户路径

- 首页 `#home`（含空 hash 与任何未识别的 hash）的视觉重心是进入**玩法菜单** `#play` 的主按钮（决策 023）；页眉保留"随机入场"快速入口与题库/榜单链接。全站页头品牌字标为 MiSans 双字重样式（移植自空间版，决策 027）。
- 玩法菜单 `#play`（仪器档案风列表）列出三种玩法（名称暂定）：**正式测评**（资格制：dev 开发者身份持有资格，决策 028；其他账号锁定展示"需要资格"）、**娱乐测评**（进入随机竞技场，即当前竞技场流程）、**特别赛·鹈鹕大乱斗**（独立页 `#event`，当前为占位页，轮换规则与独立榜单筹备中，见决策 026 与想法 P06）。
- 提示词库支持搜索提示词、按作品类型筛选，并显示每题的模型数与结果数（均不含演示样例）；可比较的题显示"进入这个竞技场"，其余显示"查看提示词（与样例）"。
- 每个提示词只有一个竞技场地址：`#arena/{promptId}`。直接打开、刷新、前进后退都以地址中的题号为准。
- 打开 `#arena/{promptId}` 时：有可比较结果则进入竞技场；没有可比较结果则进入提示词预览页（展示提示词全文；有 HTML 样例时可预览、独立打开或下载）；题号不存在则显示引导回提示词库的页面。
- 旧地址 `#arena` 与快捷地址 `#random` 自动跳转到随机竞技场。

## 数据归属

概念模型分四层：

- **Prompt（提示词）**：比较的共同题目与边界。
- **ModelResult（模型结果）**：一份作品，唯一 id，归属某提示词，记录生成它的 modelId / modelName。
- **Arena（竞技场）**：按提示词组织，同题结果才互相比。
- **Matchup（当前对局）**：一次抽出的两份结果。

同一模型可在一个提示词下有多份结果，也可出现在多个提示词下。结果不属于固定的 A/B 阵营：A/B 只是当前展示位置，每次抽组随机排列（见决策 008）。

作品数据存服务端 SQLite works 表（决策 040）：页面打开时拉取已发布作品清单，新登记的作品默认未发布、对访客不可见；拉取失败时站点回退到内置清单，行为不变。

作品按内容的四种形态呈现，用户可见差异如下：`image` 直接展示图片（当前题库未使用）；`text` 是文章卡片，入场时自动滚动巡览全文；`web` 卡片态为静态页面，展开 Dialog 后可交互点击；`html` 在只允许脚本的沙盒 iframe 中运行，卡片态不可交互，展开后可交互。

## 抽取规则

1. 只在同一提示词内配对。
2. 两份结果必须来自不同 modelId；isDemo 样例不参与配对。
3. 从符合条件的组合中均匀随机选一组，再随机分配左右位置。
4. "换一组"时，上一轮出场的两份作品下一轮都不出现（防身份泄漏：已揭晓的作品若再次出场会被认出，盲测失效）；无可避开时（如只剩一组可配）回退到全量组合，且始终留在当前题。
5. 只有一组可比较时，按钮明确显示"重新比较本提示词"，不假装还有更多作品。
6. "随机换个竞技场"才切换题目；存在其他可用竞技场时避开当前题。
7. 不足两个不同模型的题在库中展示但不提供比较入口，也不参与随机入场与随机换场；全场无可比较时随机入口退回提示词库。

## 场内状态

- 一次对局经历：载入 → 作品入场（依次放大聚焦、长文自动滚动）→ 投票 → 锁定 → 揭晓；换组、重播、切换模式时经过转场回到入场。
- 入场可跳过；A / D 键投左 / 右，N 键换一组，空格跳过入场。
- 进入竞技场、换题、同题换组与重播时自动定位到本轮命题（距视口顶部约 12px）；正常为平滑滚动，减少动态效果时直接定位。投票、揭晓与评论刷新不触发定位。
- 长提示词（超过 90 字符）在场内默认显示题目名，可展开完整内容；较矮的桌面视口收紧顶部信息，作品高度按对比区宽度计算（340–540px），不足一屏时允许整页滚动，不随揭晓缩小。选中作品底边扫动确认、结果标签依次出现，减少动态效果设置下直接呈现。
- 换组、重播或切换模式都会清除当前选择并重新走一遍流程。
- 两种玩法共用竞技场：**娱乐测评**（`#arena/{promptId}`）——身份隐藏，做出选择后才揭晓（决策 024）；**正式测评**（`#formal/{promptId}`，需资格）——任何环节都不揭示模型名称，投票后也没有评论区，选择以 formal 模式落库（决策 028）。原全程公开身份的「娱乐站队」已废除（reducer 内部的 mode 字段保留）。
- 投票落库（真实模式）：选择即向服务端提交一票（记录对局双方的作品 id 与模型 id、投票时的模式）；娱乐与正式的票计入同一偏好榜，榜单可切换「只看正式」单独查看正式票（决策 020/021/026）。揭晓区按结果显示"你的选择已计入偏好榜 / 登录后会计入（附登录入口）/ 这一对作品你已经投过票了 / 暂时没有记上"。
- 投票去重：同一账号对同一对作品只计一票（与胜负和左右位置无关）；同一模型换作品或换对手可以再投。
- 占位模式下投票只写入本地 localStorage（不入库），提示"已写入本地演示数据 · 占位模式"。
- 音效默认关闭，可手动开启；支持全屏与 reduced-motion 降级。

## 账号、评论与投票

- 注册账号为 3–24 位字母、数字或下划线（不区分大小写），密码 12–128 字符；登录状态保留 7 天，窗口重新聚焦时自动刷新会话。
- 发表评论与提交投票都必须登录（决策 007/020）：未登录可以完整游玩竞技场（看作品、选择、揭晓），只是选择不计入榜单，揭晓区给登录入口。
- 开发者面板（右下角 "dev"，本地用）提供"开发者身份"免登录：一键以固定 `dev` 账号登录，仅本机回环或服务端 `ALLOW_DEV_LOGIN=1` 时开放。
- 评论区在该题揭晓后出现，按提示词聚合为"本提示词讨论"，人人可读。
- 揭晓后两份作品保持投票前的展示尺寸；结果操作与评论区依次向下延伸。桌面评论输入与列表分两列，手机纵向排列，长评论随整页滚动（决策 037）。
- 已登录评论显示账号名；历史无主评论显示"匿名观测员 #XXXX"（编号取自评论 id 前四位）。
- 评论的 side（左右）字段仅为旧 API 兼容保留，不代表支持哪个模型，前台不展示阵营（见决策 006）。
- 单条评论 1–280 字；每 IP 每分钟最多 10 条（投票共用同一限流）。

## 扩充内容的产品层约束

- 新提示词使用三位数字 id；新结果的 id 必须唯一，promptId 指向已存在的题。
- modelId 必须稳定：同一模型在不同题、不同结果间使用同一 modelId，否则会被误认为多个模型；只有不同 modelId 的结果才成对。
- isDemo 样例的语义固定：不计模型数、不参与配对与随机竞技场，仅预览可见（见决策 009）。
- 新增题号时，评论题号白名单需在前端校验与后端两处同步更新。
- 只补齐两个不同模型的结果后，原预览页地址自动变为竞技场，无需改路由。
- 具体操作步骤见 `docs/ARCHITECTURE.md`。

## 偏好榜

- 地址 `#rank`，入口在首页（"看看偏好榜"）与竞技场揭晓区（"看看偏好榜 ↗"）。
- 榜单按模型聚合，分综合 / 写作（text 题）/ 网页（web 题）三个赛道；行内显示偏好评分（占位口径的简易 Elo，基准 1200、K=32）与参与比较次数。
- 少于 30 场的模型带"暂定"徽章；点击模型打开右侧档案卡：六维雷达（演示用模拟值，非真实测量）、胜/负/胜率、题目覆盖。
- 榜单口径可切换（决策 026）：默认混入正式与娱乐的全部票；「只看正式」仅计 mode=formal 的票。开关只在真实数据下出现——占位票没有模式之分，只在混入口径计入。
- 投票来源：真实模式从服务端拉全量投票流水、客户端重放 Elo（含 loading 与拉取失败态，"重播入场"会重新拉取）；占位模式读本地占位投票（竞技场亲手投的票 + 开发者面板生成的票），头部标注 PLACEHOLDER DATA。
- 票面在服务端按作品清单核对（伪造 rid、rid 与题号或模型不符、演示样例一律 400 拒收）；指向当前阵容之外模型的历史票（已下架作品）在聚合时被过滤，不进入榜单。
- 竞技场内投出的票实时计入：真实模式入库（登录后），占位模式写本地。
