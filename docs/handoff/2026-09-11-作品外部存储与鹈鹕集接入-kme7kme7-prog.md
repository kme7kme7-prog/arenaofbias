## 改动

- **作品外部存储（决策 043）**：
  - `server/index.js`：`WORKS_DIR` 环境变量（默认 `<DATA_DIR>/works`）；Express **无条件**把该目录挂载到 `/works/`（先于 dist 静态，data/works 优先、public/works 的演示样例回落——无条件挂载避免"先起服务后建目录"顺序坑）；启动日志打印作品目录。
  - `vite.config.ts`：dev 代理补 `/works` → 3000。
- **登记脚本 `scripts/register-works.mjs`**（npm run register:works）：
  - `--source <目录> --prompt <题号> [--draft]`；解析「标题，模型名.html」（全角逗号，无逗号时按结尾 ASCII 段回退，剥「普通-」前缀）；
  - modelId = 小写 slug，原文含非可打印 ASCII 时掺 5 位短哈希（gpt-6-astra-降智 → gpt-6-astra-1hhmw ≠ gpt-6-astra）；
  - workId = `<题号>-<modelId>`（同模型第 n 份加 -n），文件名排序保证稳定、幂等可重跑；
  - 复制原件进 `data/works/<题号>/<workId>.html`（原件不动）+ works 表 INSERT OR IGNORE（默认 published=1）。
- **登记执行**：tihu 20 份 → data/works/001/，全部发布；重跑验证幂等（0 登记、跳过 20）。
- `package.json` 增 `register:works`。
