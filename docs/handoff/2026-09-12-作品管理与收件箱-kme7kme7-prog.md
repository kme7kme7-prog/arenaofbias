- **`scripts/register-works.mjs`**：改为复用核心，CLI 行为不变；重构后对真实库回归幂等（0 登记、20 跳过，id 与重构前一致）。
- **服务端 `server/index.js`**：
  - `GET /api/admin/works`：全量清单含草稿，题号/状态/关键字筛选，倒序分页 + total；content 解析出 `src` 预览地址（损坏留空不炸列表）。
  - `PATCH /api/admin/works/:id`：标题（1–120）/模型名（1–64，仅显示名）/发布开关（布尔）；空改动 400、未知 404、跨源 403、非 JSON 415；**model_id 不可改**（榜单归组键）。
  - `GET /api/admin/inbox`：条目清单（单文件/文件夹、大小、可登记性与原因、解析建议）。
  - `POST /api/admin/inbox/register`：单文件或含 index.html 的文件夹搬进 `data/works/<题号>/` + 入库（默认草稿，`publish:true` 直接发布）；落库失败文件退回收件箱。
  - `DELETE /api/admin/inbox?name=`：清理收件箱（不进作品库）。
  - `WORKS_INBOX_DIR`（默认 `data/inbox`）启动即创建并打印；所有收件箱接口只收单段文件名（禁分隔符与 `..`）防路径穿越。
- **后台前端**：`app/admin/works.tsx`（筛选/搜索/发布开关乐观更新失败回滚/行内编辑/预览链接/加载更多）+ `app/admin/inbox.tsx`（条目卡片、解析建议预填、空题与空模型名拦截、成功消息带后继指引、不可登记件给原因可删）+ admin.css 补样式；`src/admin.tsx` 两新页解锁，题目管理/活动管理占位保留。
