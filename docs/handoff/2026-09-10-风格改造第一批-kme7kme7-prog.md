## 本轮目标

视觉风格改造第一批：围绕仪器感/终端索引的视觉语言，先落三类动效（解密揭晓、滚动数字、可打断过渡），再做细节装饰。后续在此基础上继续个性化。

## 改动

- **盲测揭晓 = 文档解密**：`lib/decryption.ts` 实现 `DocumentDecryption`。要点：`reveal()` 自起 rAF（0.95s）；目标选择器为构造参数。逐行测量（TreeWalker + Range）、错峰（0.22 铺开 / 0.78 窗口）、自定义缓动（0.4t² 起步 + 0.6(1-t)^(16/3) 长尾）。遮黑条 CSS 在 `app/globals.css`，墨色 #20221d。`app/page.tsx` 在盲测 phase→result 的 layout effect 内先盖住 `.model-identity` 再退开，身份绝不裸露；娱乐模式与减少动态效果不解密。
- 末尾提交 **滚动数字**：新增依赖 `@kitlangton/rolling-number@0.4.1`（MIT；许可存 `public/licenses/rolling-number.txt`）。运动参数：460ms、motionBlur。接到榜单行名次/评分/次数、档案卡当前名次/评分/参与比较、头部总票数。注意：库不读系统减少动态设置，各使用处显式传 `animated={!reduced()}`。
- 末尾提交 **可打断过渡**：`lib/ui-transitions.ts` 的 `SurfaceTransition`（进 300ms cubic-bezier(.22,1,.36,1) / 退 200ms cubic-bezier(.4,0,1,1)，中途反向从当前计算样式接续），接到开发者面板。两个配套要点：面板从条件渲染改为常驻挂载 + `hidden` 由 transition 实例托管（JSX 里 `hidden` 保持常量，React 不覆盖）；`.dev-panel[hidden]` 显式 `display:none`（class 的 `display:flex` 优先级高于 UA 的 hidden 规则）。
- 末尾提交 **终端索引细节**：`globals.css` 新增 `.term-ticks` 刻度尺（主刻度每 72px 全高、次刻度每 12px 半高），接到榜单表头上沿与题库计数行下方；榜单赛道 tab 加 mono 编号 01/02/03（选中变酸黄）。
- `docs/ARCHITECTURE.md`：代码地图补 `lib/decryption.ts` / `lib/ui-transitions.ts` 两行。
