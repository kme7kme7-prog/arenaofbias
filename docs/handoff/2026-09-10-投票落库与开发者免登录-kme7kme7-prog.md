## 改动

**服务端**

- `server/index.js`：votes 表（id / prompt_id / winner_rid / winner_mid / loser_rid / loser_mid / pair_key / mode / user_id / created_at）+ `votes_user_pair` 唯一索引（对局级去重）；`GET /api/votes` 全量流水升序（公开、无用户信息）；`POST /api/votes`（登录 401 / 同源 403 / 校验 400 / 重复 409 / 同 UUID 幂等 200），与评论共用 per-IP 限流。服务端只做形态校验，阵容过滤在聚合侧。
- `server/auth.js`：`POST /api/auth/dev` 开发者免登录——固定 `dev` 账号首次使用时创建，密码随机生成不留存；仅本机回环或 `ALLOW_DEV_LOGIN=1` 开放。

**前端数据层**

- `lib/votes.ts`（新）：`ArenaVote` 类型、`validateVote`（服务端规则镜像，题号白名单由题库派生）、`pairKeyOf`、`submitVote` / `fetchVotes`、`voteToRecord`（流水→榜单聚合记录）。

- `app/ranking.tsx`：`useBoardVotes` 拉取投票（真实模式 fetch /api/votes，占位模式读 localStorage）；新增 loading 与拉取失败空态；"重播入场"兼为"重新拉取"。

## 决策

- 决策 018：两种模式当前都需登录才计分；娱乐免登录为长期方向；开发者面板免登录。
- 决策 019：去重单位是「对局」（两份作品，pair_key 与胜负/左右无关）；votes 同时存作品级 rid 与模型级 mid（决策 006 落地）；mode 落库但当前不分流。
- 设计取舍（未入决策日志）：表里只存流水不存 Elo，评分由客户端重放（算法单点、换口径免迁移）；占位投票不入库打 scope 标记（占位阵容按浏览器隔离，入库会互相污染）。
