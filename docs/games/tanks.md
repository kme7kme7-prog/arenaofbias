# 坦克斗蛐蛐

主站菜单第五项进入 `/tanks.html`，沿用色块横推进出。线上状态以 HANDOFF 发布记录为准。

## 玩家流程

1. 初始为空场。挑选基底战场，从可搜索坦克库选入四份不同 AI 程序；右侧可以换选手、移除或换颜色。
2. 可直接开始，也可拖动坦克改变起点、旋转朝向。AI 身份始终跟随这辆坦克；调整席位需要明确交换选手。
3. 点击开始后，在本机计算完整对局，再自动播放。可以取消计算。
4. 回放支持暂停、单步、倍速、拖动进度、点击事件回看、可选音效及保存/打开文件。

坦克库提供二十一份已登记的最终作品，每局任选四份。首批四份为：GLM-5.3 Flash 的红隼、GPT-6 Luna 的 Tank26、GPT-6.1 SOL 的 vector、GPT-6 Astra 的 astra-knife。新增 DeepSeek V4.1 Flash 的 shrike（伯劳）、GLM-5.3 的伯劳 SHRIKE、Kimi K3 的 kestrel；Grok 4.7 的 sidecut、Claude Haiku 5.5 的 ghostline、Claude Opus 5.5 的 Parallax（视差）。结算标题和排名显示作者模型名。同一模型可以登记多个独立作品，并在同一局同时入场；去重按作品ID，不能重复选中同一份程序。同模型作品的结算附作品名以区分。每份作品标记创作时的思考强度，现有astra-knife为medium、Tank26为max，新增GPT-5.6 Luna的iron-ambush、GPT-5.6 SOL的Rift Harvest（裂隙收割者）和GPT-6 Astra的Parallax均为max，其余八份现有作品为high，标签随回放保存。不是每回合重新调用大模型。

## 战场规则

- 26×26 格，坦克占2×2格；三条命、两格装甲，最多600 tick / 60秒。
- 砖墙可破坏、钢墙阻挡车与弹、河道挡车不挡弹、草地隐蔽；中央定时补给。
- 20秒开始缩圈，45秒短暂雷达曝光，50秒起全场坦克持续可见。
- 排名按原引擎规则：运行有效者优先、仍有生命者优先，再比较积分、击毁、剩余命数与装甲；完全相同允许并列。命中得分、击毁加分均使用引擎记录。
- 网站单次决策预算500ms，启动/无响应看门狗10秒。异常选手出局，其他选手继续；取消则不产生结算。此处是娱乐对局，不写入正式排名，原组织者50ms比赛条件不改。

## 实验玩法

修改起点或自绘地图即标注为实验玩法。画笔含五种地形、一格/两格、四向对称、逐笔撤销与清空；允许非对称、死路和困局，但拒绝越界、非法地形、坦克压墙/水或重叠。

桌面拖动或用方向键布阵，R转向；手机可先选AI，再点地图放置。自定义起点也作为复活搜索参考。地图、席位、种子和起点保存为本机草稿，“撤销全部”恢复当前基底地形和起点，保留已选程序与配色；回放文件包含完整实验地图和真实结算，重新打开无需计算。

“新手引导”逐步聚焦真实按钮并讲解操作，支持上一步、跳过和随时退出，不修改布置。自绘入口明确标为实验功能。

程序来源、集成边界和验证命令见 `app/tanks/README.md`。暂不接受任意上传 bot，不实现对局服务、在线模型调用或成绩上报。
