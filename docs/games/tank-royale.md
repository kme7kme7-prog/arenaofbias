# 坦克大逃杀（实验玩法）

入口：`/tanks.html?mode=royale`，从坦克页标题下「大逃杀」进入；两模式之间沿用通用色块横推。原四人场规则和原始 bot 文件保持不变。

## 本版行为

- 在现有坦克库中自由勾选至少两件作品，支持全员入场；按作品 ID 区分，同模型的多件作品可以同时参赛。没有四人席位上限，实际规模受浏览器资源限制。
- 标准地图至少 42×42，广域至少 58×58；人数增多后继续扩展。三个可复现的种子战场：碎墙荒原、雾林边境、最后旷野。出生点不重叠，座次分配由种子打乱。
- 每辆坦克两条命、每条命两格装甲，2×2 体积。移动、子弹速度、开火冷却与伤害保护沿用 2.6 战斗语义；独立 combat 副本仅动态化地图边界，增加护盾命中。
- 10 拍为一秒；第 200 拍开始，每 30 拍收缩一格，直到安全区为空。圈外每 10 拍掉一格装甲，无视护盾。没有第 600 拍或其他计时积分结算；最后幸存者获胜，同拍全灭无人生还，同拍淘汰并列名次。
- 自动拾取：维修 +1 装甲；速射持续 80 拍；护盾抵挡一发炮弹，不叠加；雷达显示全场坦克 80 拍。每 80 拍刷新一批，地图上可并存多份。旧 bot 继续读取最近的 `arena.supply`，也提供完整 `supplies` 数组。
- 浏览器先完成整场推演，再播放本地回放；保留每份 bot 的持久 Worker，单次预算 500ms，10s 无响应终止。可取消，程序异常/超时会明确显示，失效选手不获胜。不调用模型，不写正式战绩。
- 观战可暂停、0.5/1/2/4 倍速、拖动回看、点击选手或坦克关注；炮弹按微步轨迹插值，护盾与受击有独立反馈。纸面/墨色，桌面战场固定视口，手机纵向排列。

## 代码与兼容边界

`app/tanks/entry.mjs` 分流原四人应用与 `royale/app.mjs`。新模式全部位于 `app/tanks/royale/`，不改旧引擎。`engine.mjs` 为动态人数、地图、圈、补给与结算；`render.mjs` 为动态画布；`combat.mjs` 保持原子弹结算顺序。

21 份兼容副本在 `royale/bots/`，由 GPT-6 Luna 按用户指派移植。原始文件仍在 `app/tanks/bots/`，不改原始 SHA。每份几何与规则移植说明见 `app/tanks/royale/PORTING.md`。只调整地图维度、缓冲区、座次、地图中心/锚点、真实缩圈数据；不为胜率重写攻击与风险权重。新加入原库的作品需要对应兼容副本，缺失时报错，不默默使用原版。

回放仅存在当前页面内存中，模式版本 `royale-1`，不走旧四人回放验证器。保存初始地图和每帧砖墙破坏增量，回退从初始地图重建；每帧坦克、分数、补给、圈和弹道完整记录。选手记录区分 `originalSha256` 与实际执行文本的 `sourceSha256`，标明 `sourceVariant: royale-port-v1`。本版未新增回放文件导入/导出，也未扩展手绘地图编辑器。

原地图决策差分只是有限样例的兼容证据，不能保证新地图下的实力或排名不变。自动拾取新道具不表示旧 bot 已有针对它们的最优策略。部分作者自带的终局时间启发保持，可能在新节奏下提前生效。浏览器 Worker 用于执行隔离与取消，不作为恶意程序的安全沙箱；仍只运行登记的作品。

## 验证入口

- `node scripts/validate-royale-engine.mjs`：动态人数、圈自然终结、道具、取消、26×26 combat 差分等。
- `node scripts/validate-royale-ports.mjs`：原文件边界、26×26 决策对照、42/58 地图及 P27 席位。
- `ROYALE_ORIGIN=http://127.0.0.1:5464 node scripts/validate-royale-browser.mjs`：真实 Worker 全员对局、各屏幕/主题、回放和双向过场。PowerShell 使用 `$env:ROYALE_ORIGIN=...`。

当前为本地预览；没有自动提交、推送或部署。

- 两条命版本 `royale-2`：首次阵亡在该拍战斗结束后恢复两装甲，优先在圈内合法空位、远离其他坦克和现存炮弹重新入场；圈内无位则用圈外空位，风暴照常生效，不增加无敌。清除护盾、速射、雷达等增益，保留 bot 记忆和累计战绩；第二次阵亡才最终淘汰。回放复活为位置切换，不跨地图滑行。

- 观战名单默认收起，可展开「存活排名 · 击杀」；展开仅在有限高度内滚动。存活者在前、已淘汰按存活时间排序，同拍并列，数据取当前回放帧。点击行可固定查看该作品。
- 战场信息卡：悬停后移开保留2.8秒，点击固定，支持收起展开和关闭/Escape。卡片在目标对角出现并保持位置，显示实时命数/装甲/击杀/伤害；四人赛共用同一交互。
