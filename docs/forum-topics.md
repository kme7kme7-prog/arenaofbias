## 产品约定

- 文字目录保留一个「弱智吧问答」入口。每个问题有独立 task ID、回答池和投票记录。
- 「下一题」切换到下一道有可比回答的弱智吧问题，最后一道返回第一道。
- 「同题库下一题」留在当前问题，重新抽取一组回答；仅有一道可用题目时仍能换组，「下一题」禁用。
- `kind: text` 且带 `弱智吧` 标签的问题使用现有论坛呈现；旧题 ID 保留兼容。
- 原入口题暂不可用时，入口选择其他可用的弱智吧问题，不创建第二个卡片。
- 这批问答仅用于竞技场娱乐玩法。正式盲测和展览馆都不能显示该问题或回答。
