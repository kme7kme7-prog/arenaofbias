竞技场 / 比例与动效对照

使用真实页面检查完整时间轴。首次入场：路由过场层完全离场后开场牌才开始播（不与 convoy/page-wipe 扫出叠放），开场牌结束再聚焦 A，随后回位、聚焦 B、收尾静止拍，无溢出内容约 6.0 秒到可投；重播先走全屏切换幕，不重复开场牌，内部 A/B 约 5.2 秒。「逐个巡览」开关（aob-arena-tour）关闭时入场只保留开场牌，直接开放投票。不得等待 animation.finished 控制解锁，跳过后无 transform/spotlight 残留。投票后按选择反馈牌收束 → 身份遮黑解密 → 两侧判断 → 模型反应 → 提示词条 → 结果操作 → 评论区接力；娱乐「下一题」以 convoy 斜幕横推盖住场内区域（实时对比行→操作行）后切题，其余区域即时更新，新开场牌在斜幕扫出后才开始，不先跳到 0。手机检查边界和英文换行；减少动态效果直接进入终态。此页不注入投票或身份数据，登录状态下投票会正常记录。断言：node scripts/check-vote-split.mjs 与 npm run check:arena-scroll。
