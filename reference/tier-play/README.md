# 主站接入说明（2026-10-12）

正式入口为 `/tier.html`，菜单第四项「野榜制造」可直接进入，并使用色块横推返回菜单。`app/tier/` 从实时公开题库读取原文和隔离场景；每题最多八个不同模型、至少两件，无法原生阅读的HTML文字不进入，不复制本地文本作为兜底。19题和Logo映射沿用已认可试玩，真实3D预览在 `public/tier/posters/`。

揭晓白色牌是正方形，Logo采用最终认可大小，同档间距收紧；榜单框架保持，结果牌按紧凑方形重新排列。分享生成本地PNG，不上传名次，不计正式成绩。运行验证：`npm run build:check` 后 `node scripts/validate-tier-entry.mjs`。

以下记录独立本地试玩的缓存环境及历史验证方式，不是生产数据服务或生产部署命令。

# 野榜制造 · 独立试玩

一个娱乐排档小游戏。沿用景窗边框，候场区拖动匿名作品，点击卡片或「放大看」打开真实 3D / 文字全文。五档允许并列和空档；全部排好后翻成模型 Logo 榜，可以导出 PNG。只在当前浏览器会话保存进度，不计正式榜成绩。

最新细调：桌面右侧候场加宽至380px（2K为440px），左榜相应收窄；去掉心头好和排满后的眼缘文案。「分享榜单」生成题目名加「偏好榜」的PNG，底部保留 ARENA OF BIAS / 野榜制造 · 个人喜好。

当前可随机换 19 道题：11 道 3D 与 8 道文字，共 147 件真实缓存作品。每题按不同模型选择最多 8 件；深夜聊天 7 件、停电 4 件，数量如实显示。默认仍是原来的「营造法式」八件作品。`topics.json` 记录准确作品 ID；身份来自现有公开清单与 Gallery 注册表，不编造模型归属。原始 HTML、作品库、线上后端和主站入口均未改。

## 启动

在仓库根目录运行：

```powershell
# 首次或有意更新名单时，先生成本地清单（只读现有库）：
node scripts/prepare-tier-catalog.mjs
node scripts/serve-tier-play.mjs 5458
# 服务运行时，在另一个终端补齐各题实际缩略图：
node scripts/prepare-tier-play.mjs http://127.0.0.1:5458 --all
```

打开 `http://127.0.0.1:5458/`。静态预览使用 5458，隔离作品域使用 5459。服务只接受 GET/HEAD；使用既有 `.local/object-stage/sources.json`、`.local/object-stage-library/works.json` 和缓存源文件，因此不是可直接发布的生产功能。

- 缩略图是实际 800×600 场景截图，写入忽略目录 `output/tier-play/posters/`；没有生成替代作品，也没有裁切或拉伸源图。
- 桌面改为左侧完整高度的五档榜单、右侧两列候场展架，八件同时可见；窄屏继续底部横向候场。入档后 3D 使用整张 4:3 画面，文字使用较宽的摘录牌；移除重复的“匿名作品”行，编号贴角。点整张卡片查看，悬停/聚焦显示放大按钮，拖过 6px 开始排档。候场网格拖动按实际行列插入，榜内仍横向排序。
- 放大从卡片位置按统一比例展开约 320ms，关闭约 220ms 收回，场景加载与展开同时开始。关闭/切换立即卸载 iframe；常速 / 减少动态、连续切换、快速开关与 Escape 取消均有检查。窗口内可连续看上一件 / 下一件，并直接点档位。
- 3D 放大只挂载一个沙箱 iframe。初始场景必须同时完成绘制、镜头就绪和加载遮罩消失。试玩服务将现有 playground bridge 的最终 ready 信号改为独立名字，避免历史作品自己的早期探针误开遮罩；共享后端文件未修改。
- 文字牌只显示原文开头片段（最多110字），问答/消息/来信/故事有轻量区分；共同题目与简明要求固定在榜单上方，“题目全文”可查看完整原始提示词。放大用正文阅读器，聊天保留原问题和分段气泡，短问答/信件/等待采用较矮窗口，长故事完整滚动。按 `textContent` 插入，不运行作品 HTML；已有 HTML 故事提取结果先核对原文件 SHA-256。没有改写回答或添加假聊天。
- 「换个题目」随机选择另一题，清空当轮档位并重新匿名；先准备清单/缩略图再替换，失败保留当前榜单并恢复按钮。准备中禁重入和揭晓，揭晓/导图中禁换题。刷新恢复当前题、档位和已揭晓结果。
- 普通拖动、同档插入、拖回候场区、撤销；也可选中后点档位，或卡片聚焦后按 1–5。Enter 放大，Escape 关闭/取消拖动。
- 同一会话刷新保留档位和匿名字母映射；揭晓后锁定位置，重新排需确认。纸/墨两套配色。
- 揭晓时先准备当题全部 Logo，再用约 0.4 秒翻牌把作品图、画框和匿名编号替换为 Logo 与完整型号。排序与揭晓共用档位宽度、行高和卡片尺寸；候场区保留固定空间，整张榜不会因排满或揭晓而跳动。减少动态模式直接切换。Logo 读取失败时保留匿名排序，可重试；刷新已揭晓的榜单不会先闪匿名作品。
- Logo 沿用 Gallery 的 11 份原始品牌资产，30 个 modelId 精确映射且原图字节一致；来源见 [品牌来源](assets/brands/SOURCES.md)。未改 Gallery。点模型可回看原作品，导出只包含 Logo 和型号及当前题名，重新排恢复匿名作品画框。
- 保留窄档位列和紧凑间距，排序/揭晓共用卡片外形和位置。揭晓仅换 Logo 与型号，候场空间不收起；PNG 继续采用已认可的方牌。
- 普通桌面画幅限1600px、大屏1720px。场景上方仅题名；文字题增加真正需要的共同情境，不恢复大标题或重复口号。
- 桌面一屏；窄屏榜单行和候场区可以横向翻看，并提供候场区左右按钮。低于 660px 高度保留最小可操作高度。
