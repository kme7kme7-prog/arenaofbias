# 玩法菜单样板

已认可的纸面菜单方向扩展至十三项，并已接入主站 `#play`。三页、每页最多六格，每项都有可读的短说明、独立封面和对应预览；本目录仍可独立对照。发布状态见根目录 `HANDOFF.md`。

```sh
node scripts/serve-menu-demo.mjs
```

打开 <http://127.0.0.1:5456/reference/menu-demo/?v=collection>。`MENU_DEMO_PORT` 可更改端口，`?mode=werewolf` 等参数可直接查看指定玩法。菜单和素材直接来自本目录；字体复用现有资源。

## 设计与操作

- `modes.mjs` 管理目录与各场景；`controller.mjs` 管理选中、翻页、局部示意和导航，主站与独立 `menu.mjs` 共用。`forum-menu.css` 保留已认可样板，`collection.css` 补充其余玩法。
- 左侧标题下写明玩法，封面复用既有 `app/play-menu-art.tsx` 图案；可用 `node scripts/export-menu-motifs.mjs` 重新导出。素材和来源见 [assets/SOURCES.md](assets/SOURCES.md)。
- 各页分别记住选项，方向键/Home/End/PageUp/PageDown 可操作。独立 demo 用查询参数保留选项；主站保留自身 `#play` 路由。
- 1080P 与 2K 桌面保持一屏；2K 限制画幅，窄屏自然排布。无声音、自动轮播或常驻动画，遵守系统减少动态偏好。
- 保留随心玩的已核实原文、匿名揭晓、重置；启动时横推色块，返回时清理遮罩与忙碌状态。
- 四个实际入口沿用原地址，本地主站与目的页由 `dist/` 提供。独立菜单直接读取源码；主站变更需 `npm run build`。`app/play-menu.tsx` 负责接入原过渡/账号/主题/语言，Vite 插件隔离样式，素材按构建地址导入。

## 检查

```sh
node scripts/validate-menu-demo.mjs
npm run build:check
node scripts/validate-play-menu.mjs
node scripts/validate-library-pages.mjs
```

使用已安装的 Edge 和本机临时静态服务，检查九组尺寸、所有十二项的排版与状态、键盘分页、快速切换、各场景的示意操作、原文与署名、无写请求和浏览器错误。截图与结果位于 `output/menu-collection/`。导航目的页由检查脚本模拟，只验证菜单入口和历史返回，不代表主站玩法全流程回归。

`validate-play-menu` 检查实际构建后的主站：布局、中英文、纸面/墨色、控件及现有目的页往返，证据 `output/play-menu-integration/`。后端和展览馆使用桩数据，不启动真实比赛或提交真实投票。
